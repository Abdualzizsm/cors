# محرر المحتوى بالذكاء الاصطناعي

تطبيق ويب يوفر خدمات كتابة وتحسين المحتوى باستخدام الذكاء الاصطناعي من خلال واجهة محرر سهلة الاستخدام. يستخدم التطبيق نموذج Google Gemini لتحسين النصوص وتقديم اقتراحات للكتابة.

## المميزات الرئيسية

- محرر نصوص متقدم سهل الاستخدام مع دعم كامل للغة العربية
- تحسين المحتوى تلقائيًا بواسطة الذكاء الاصطناعي
- اقتراحات ذكية لتحسين النص
- قوالب مختلفة للمحتوى (مقالات، وصف منتجات، منشورات اجتماعية، بريد إلكتروني)
- واجهة مستخدم سهلة وبسيطة
- حفظ تلقائي للمحتوى في المتصفح
- خاصية المعاينة قبل النشر
- **ملف HTML واحد فقط** - لا يحتاج إلى خادم أو تثبيت

## التقنيات المستخدمة

- **HTML5** مع CSS و JavaScript مضمنة
- **الذكاء الاصطناعي**: Google Gemini API

## طريقة الاستخدام

### الطريقة الأسهل
1. افتح ملف `index.html` مباشرة في المتصفح
2. ابدأ باستخدام المحرر مباشرة

### باستخدام خادم محلي (اختياري)
إذا كنت تريد اختبار التطبيق على خادم محلي:

```bash
# باستخدام Python
python -m http.server 8000

# أو باستخدام Node.js
npx http-server
```

ثم افتح المتصفح على: `http://localhost:8000/index.html`

## ملاحظات هامة

- التطبيق يستخدم Google Gemini API لتحسين المحتوى. يمكنك استبدال مفتاح API في الملف `index.html` بمفتاحك الخاص
- يتم حفظ المحتوى محليًا في متصفحك باستخدام LocalStorage
- التطبيق يعمل بدون الحاجة إلى خادم ويب - يمكن فتحه مباشرة من الملف

## هيكل المشروع

### الإصدار الجديد (ملف واحد)
- `index.html` - ملف HTML واحد مستقل يحتوي على كل شيء (HTML, CSS, JavaScript)

### الإصدار القديم (Flask)
الملفات التالية هي للإصدار القديم الذي يعتمد على Flask:
- `app.py` - تطبيق Flask
- `templates/` - قوالب HTML
- `static/` - ملفات CSS و JavaScript
- `requirements.txt` - متطلبات Python
