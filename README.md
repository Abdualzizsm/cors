# محرر المحتوى بالذكاء الاصطناعي

تطبيق ويب يوفر خدمات كتابة وتحسين المحتوى باستخدام الذكاء الاصطناعي من خلال واجهة محرر سهلة الاستخدام. يستخدم التطبيق نموذج Google Gemini 2.5 Pro لتحسين النصوص وتقديم اقتراحات للكتابة.

## المميزات الرئيسية

- محرر نصوص متقدم سهل الاستخدام مع دعم كامل للغة العربية
- تحسين المحتوى تلقائيًا بواسطة الذكاء الاصطناعي
- اقتراحات ذكية لتحسين النص
- قوالب مختلفة للمحتوى (مقالات، وصف منتجات، منشورات اجتماعية، بريد إلكتروني)
- واجهة مستخدم سهلة وبسيطة
- حفظ تلقائي للمحتوى
- خاصية المعاينة قبل النشر

## التقنيات المستخدمة

- **الواجهة الخلفية**: Python, Flask
- **الواجهة الأمامية**: HTML, CSS, JavaScript
- **محرر النصوص**: TinyMCE
- **الذكاء الاصطناعي**: Google Gemini API

## متطلبات التشغيل

- Python 3.9+
- متطلبات Python المذكورة في ملف `requirements.txt`
- مفتاح API لـ Google Gemini

## طريقة التشغيل محليًا

1. قم بتثبيت متطلبات المشروع:
```bash
pip install -r requirements.txt
```

2. قم بإعداد متغيرات البيئة:
```bash
cp .env.example .env
# ثم قم بتحرير ملف .env وأضف مفتاح Gemini API الخاص بك
```

3. قم بتشغيل التطبيق:
```bash
python app.py
```

4. افتح المتصفح على العنوان: `http://localhost:5000`

## النشر على هوستينجر

للحصول على دليل مفصل حول كيفية نشر التطبيق على خدمة الاستضافة هوستينجر، راجع ملف:
📋 **[دليل النشر على هوستينجر](HOSTINGER_DEPLOYMENT.md)**

### خطوات سريعة:

1. **رفع الملفات**: ارفع جميع ملفات المشروع إلى `public_html`
2. **إعداد Python**: أنشئ Python App في cPanel
3. **متغيرات البيئة**: أضف مفتاح Gemini API في إعدادات البيئة
4. **الاختبار**: تأكد من عمل التطبيق على نطاقك

### ملفات مهمة للنشر:
- `.htaccess` - إعدادات الخادم والأمان
- `.env.example` - قالب لمتغيرات البيئة
- `wsgi.py` - نص بدء التشغيل للإنتاج
- `HOSTINGER_DEPLOYMENT.md` - دليل النشر المفصل
