# محمل اليوتيوب - أداة تحميل وتحويل الفيديو والصوت

تطبيق ويب احترافي لتحميل الفيديوهات والملفات الصوتية من اليوتيوب بجودة عالية وتحويلها إلى صيغ مختلفة.

![YouTube Downloader](https://github.com/user-attachments/assets/699d16b4-c6d8-477a-807b-0a65a6901225)

## المميزات الرئيسية

### 🎥 تحميل متقدم
- تحميل فيديوهات اليوتيوب بجودات مختلفة
- تحويل إلى MP3, WAV وصيغ أخرى
- دعم كامل للروابط المختلفة من اليوتيوب

### 🎨 تصميم احترافي
- واجهة باللغة العربية مع دعم RTL
- تصميم أخضر وأبيض أنيق ومعاصر
- متجاوب تماماً مع جميع أحجام الشاشات

### ⚡ الأداء
- سريع وسهل الاستخدام
- معالجة في الوقت الفعلي
- رسائل خطأ واضحة باللغة العربية

### 📱 التوافق
- يعمل على جميع المتصفحات الحديثة
- متوافق مع الأجهزة المحمولة
- لا يتطلب تسجيل أو اشتراك

## التقنيات المستخدمة

- **الواجهة الخلفية**: Python 3 مع HTTP Server
- **الواجهة الأمامية**: HTML5, CSS3, JavaScript
- **التصميم**: CSS Grid, Flexbox, الاستجابة الكاملة
- **الخطوط**: Tajawal (Google Fonts)
- **الأيقونات**: Font Awesome

## كيفية التشغيل

1. **تثبيت المتطلبات:**
```bash
pip install -r requirements.txt
```

2. **تشغيل الخادم:**
```bash
python app.py
```

3. **فتح المتصفح:**
```
http://localhost:5000
```

## كيفية الاستخدام

1. **انسخ الرابط**: انسخ رابط الفيديو من اليوتيوب
2. **اختر الصيغة**: حدد الصيغة المطلوبة (فيديو أو صوت)
3. **حمل الملف**: اضغط على تحميل واحصل على ملفك فوراً

## الصيغ المدعومة

### فيديو
- MP4 (جودة عالية)
- WebM
- FLV

### صوت
- MP3 (جودة عادية)
- WAV (جودة عالية)
- M4A
- OGG
